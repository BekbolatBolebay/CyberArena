CyberArena — студенттер мен мамандарға арналған ашық кодты зертхана. Жүйе компьютеріңіздің CPU, RAM және дискісін өзі тексеріп, қыздырмайтын оңтайлы режимді (LIGHT / BALANCED / FULL) автоматты таңдайды.

$ git clone https://github.com/BekbolatBolebay/CyberArena.git && cd CyberArena && ./arena.sh auto
Қуат калькуляторы GitHub кодын көру

⚡ Ноуттың қуатына автоматты адаптация

Слайдты жылжытып, компьютеріңізде қай режим іске қосылатынын тексеріңіз:

BALANCED

Орташа режим (~768 MB RAM)

Іске қосылатын жүйелер:
    LIGHT

    ≤ 4 GB RAM немесе Docker-сіз

    Тек таза Python-да Portal + IP Camera (~60 MB RAM). Ескі ноутбуктерде де қызбайды.

    BALANCED

    5–11 GB RAM + Docker

    Portal + IP Camera + OWASP Juice Shop (қатаң CPU/RAM лимитімен).

    FULL

    12+ GB RAM, 6+ CPU + Docker

    Толық полигон: Portal + Juice Shop + DVWA + IP Camera.

    🎭 «Who Am I» стиліндегі 6 миссия

    Әр операцияда шабуыл механизмін зерттеп, соңында Blue Team қорғанысын меңгересіз.

    OP-01 · RECON

    MRX-тің ізі

    /robots.txt пен жасырын каталогтарды тексеру арқылы бастапқы барлау.

    OP-02 · SNIFFING

    Ашық Wi-Fi торы

    Шифрланбаған HTTP трафик пен Base64 токенін талдау.

    OP-03 · SQLI

    Темір есікті алдау

    Оқшауланған in-memory симуляторда SQL инъекциясын және Prepared Statement-ті үйрену.

    OP-04 · FORMJACKING

    Кіреберістегі тыңшы

    Формадан дерек ұрлайтын JS скриптті табу және CSP қорғанысы.

    OP-05 · IOT

    Көлеңкелі камера

    IP-камерадағы зауыттық құпия сөздер қаупін тексеру.

    OP-06 · BLUE TEAM

    Анти-DDoS Қалқан

    Nginx access-логтарынан ботнет подсетін анықтап, WAF ережесімен жабу.

    30 секундта іске қосыңыз

    Толық ашық код (MIT лицензиясы). Жүйе порттарды тек 127.0.0.1-де ашады — сыртқы желіге қауіпсіз. 

    git clone https://github.com/BekbolatBolebay/CyberArena.git
