# 🛡️ CyberArena: Жеке Қауіпсіз Кибер-Полигон

Бұл полигон — **Parrot OS** құралдарының толық күшін сынауға арналған, 100% оқшауланған, ноутбукті қыздырмайтын кәсіби зертхана.

---

## ⚡ Неге бұл қауіпсіз және ноутбук қызбайды?

1. **Ноутбук қызбайды:** Әрбір серверге қатаң шектеу қойылған (максимум `0.5 CPU` және `512 МБ RAM`). Процессор тыныш жұмыс істейді, желдеткіш шуламайды.
2. **Вирустар сыртқа шықпайды (Sandbox):** Барлық жүйелер оқшауланған контейнерде жұмыс істейді. Контейнер ішінде вирус жарып жіберсеңіз де, ол сіздің ноутыңызға немесе жеке файлдарыңызға еш әсер ете алмайды.
3. **Үй желісіне қауіп жоқ:** Барлық порттар тек `127.0.0.1` (локалды машинаға) ғана байланған. Сыртқы Wi-Fi-дағы адамдар бұл алаңды көрмейді.

## 🚀 Аренаны басқару (Пульт):

Папкаға өту:
```bash
cd ~/Documents/CyberArena
```

* **Аренаны іске қосу:**
  ```bash
  ./arena.sh start
  ```
* **Трафикті «ауадан/желіден» ұстау (Sniffing):**
  ```bash
  ./arena.sh sniff
  ```
* **Хакерлік әрекеттердің логтарын нақты уақытта бақылау (Blue Team):**
  ```bash
  ./arena.sh logs
  ```
* **Ноуттың жады мен температурасын тексеру:**
  ```bash
  ./arena.sh status
  ```
* **Аренаны толық өшіру (ресурстарды босату):**
  ```bash
  ./arena.sh stop
  ```

## ⚔️ Сіздің алғашқы 3 миссияңыз:

### 1-Миссия: Барлау (Reconnaissance)
Parrot OS-тің басты қаруы — **Nmap** сканерін қосыңыз:
```bash
nmap -sV -p 3000,8080 127.0.0.1
```
*Мақсат:* Серверде қандай нұсқалар мен қызметтер тұрғанын анықтау.

### 2-Миссия: Трафикті ұстап алу (Packet Sniffing)
1. Бір терминалда трафик ұстағышты қосыңыз:
   ```bash
   ./arena.sh sniff
   ```
2. Браузерден `http://127.0.0.1:3000` дүкеніне кіріп, кез келген логин-пароль теріп көріңіз.
3. `Ctrl + C` басып тоқтатыңыз. Пайда болған `.pcap` файлын Wireshark-пен ашыңыз:
   ```bash
   wireshark pcaps/*.pcap &
   ```
4. Фильтрге `http` деп жазып, өзіңіз енгізген парольді ашық түрде көріңіз!

### 3-Миссия: Серверді қорғау (Blue Team)
`./arena.sh logs` пәрменін ашып қойып, шабуыл жасалған кезде сервер логтарында қандай іздер қалатынын көріңіз. Хакерді қалай әшкерелеу керектігін осылай үйренесіз!
